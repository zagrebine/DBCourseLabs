# Семинар 5 — Использование функций и агрегирование данных

## Цель работы

Изучить встроенные функции T-SQL, функции ранжирования и методы агрегирования данных в Microsoft SQL Server на примере базы данных AdventureWorksLT.

В ходе лабораторной работы необходимо изучить:
- Использование строковых, числовых функций и функций даты.
- Преобразование и фильтрацию данных.
- Ранжирование клиентов по выручке.
- Группировку данных с помощью GROUP BY.
- Использование агрегатных функций.
- Фильтрацию групп с помощью HAVING.
- Сортировку результатов запросов.

## Используемые технологии

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- База данных AdventureWorksLT
- Язык запросов T-SQL

## Подготовка к работе

Для выполнения лабораторной работы необходимо установить Microsoft SQL Server и SQL Server Management Studio либо получить доступ к Azure SQL Database. После подключения к серверу следует убедиться в наличии базы данных AdventureWorksLT и выбрать её для выполнения запросов.

## Задача 1. Получение информации о товарах

### 1.1. Наименование и приблизительный вес каждого товара

В первой части необходимо получить идентификатор и наименование каждого товара, а также его приблизительный вес.

Для отображения названий товаров в верхнем регистре используется функция UPPER(). Для округления веса до ближайшего целого числа применяется функция ROUND().

В результате формируется список товаров с идентификаторами, названиями в верхнем регистре и округлёнными значениями веса.

### 1.2. Год и месяц начала продаж товаров

На следующем этапе необходимо дополнить сведения о товарах информацией о дате начала продаж.

Функция YEAR() позволяет извлечь год из даты начала продаж, а функция DATENAME() возвращает название месяца.

В результате для каждого товара отображаются год и месяц, когда компания начала его продавать. Название месяца зависит от языковых настроек SQL Server.

### 1.3. Определение типа товара по номеру

Для определения типа товара используется его номер, содержащийся в столбце ProductNumber.

Функция LEFT() извлекает заданное количество символов из начала строки. В данной задаче необходимо получить первые два символа номера товара и сохранить их в столбце ProductType.

Это позволяет выделить начальную часть номера, которая может использоваться для классификации товаров.

### 1.4. Выбор товаров с числовым размером

В этой части требуется отобразить только те товары, размер которых представлен числовым значением.

Для проверки возможности преобразования значения размера в целое число используется функция TRY_CONVERT(). Если преобразование невозможно, функция возвращает NULL.

Таким образом, в итоговый список включаются только товары, размер которых можно преобразовать в целое число.

## Задача 2. Ранжирование клиентов по доходу

### 2.1. Компании, ранжированные по сумме продаж

Цель задачи — получить список компаний и определить их положение в рейтинге по выручке.

Для получения названий компаний и сведений о заказах используются таблицы клиентов и заголовков заказов, связанные по идентификатору клиента.

Функция RANK() присваивает каждой записи ранг в соответствии с указанным порядком сортировки. Для формирования рейтинга по убыванию выручки используется сортировка от большего значения к меньшему.

Если несколько записей имеют одинаковую выручку, они получают одинаковый ранг. Следующий ранг при этом может быть пропущен.

При расчёте рейтинга компаний по общей выручке необходимо сначала объединить заказы каждой компании и вычислить сумму всех её продаж. Для этого используется агрегатная функция SUM() совместно с GROUP BY.

В результате можно получить список компаний, их общую выручку и место в рейтинге.

## Задача 3. Агрегирование данных по продажам товаров

### 3.1. Общий объём продаж каждого товара

В первой части задачи необходимо определить общую выручку по каждому товару.

Для этого используются таблицы товаров и деталей заказов, связанные по идентификатору товара.

Функция SUM() вычисляет сумму значений LineTotal, то есть общую стоимость строк заказов для каждого товара. Конструкция GROUP BY объединяет записи по идентификатору и названию товара.

Для удобства анализа результаты сортируются по убыванию общей выручки. Это позволяет увидеть товары, принёсшие наибольший доход, в начале списка.

### 3.2. Товары с ценой выше 1000 долларов

На следующем этапе необходимо ограничить список товарами, цена которых превышает 1000 долларов США.

Для фильтрации используется условие по столбцу ListPrice, содержащему розничную цену товара.

Фильтрация выполняется с помощью WHERE до группировки данных. Поэтому в расчёте общей выручки участвуют только товары, удовлетворяющие условию по цене.

Результат содержит названия подходящих товаров и их общую выручку, отсортированную по убыванию.

### 3.3. Товары с общей выручкой выше 20000 долларов

В заключительной части задачи требуется оставить только те группы товаров, общая выручка которых превышает 20000 долларов США.

Для этого применяется конструкция HAVING, позволяющая фильтровать результаты после группировки и агрегирования данных.

В данном случае одновременно используются два условия:

- Цена товара должна превышать 1000 долларов США.
- Общая выручка по товару должна превышать 20000 долларов США.

Условие WHERE применяется к отдельным товарам до группировки, а HAVING — к итоговым значениям выручки после группировки.

В результате формируется список товаров, которые соответствуют обоим критериям.
