# Семинар 2 — Запросы к таблицам SELECT

## Обзор

В рамках второго семинара рассматриваются запросы `SELECT` для извлечения, сортировки и фильтрации данных из учебной базы данных **AdventureWorksLT2019**.

В ходе работы используются основные операторы и конструкции языка Transact-SQL:

- `SELECT`
- `DISTINCT`
- `FROM`
- `WHERE`
- `ORDER BY`
- `TOP`
- `PERCENT`
- `OFFSET`
- `FETCH`
- `LIKE`
- `IN`
- `AND`
- шаблоны поиска с `%`, `_`, `[ ]` и `[^ ]`

## Цель работы

Закрепить навыки получения и фильтрации данных из таблиц базы данных с помощью запросов `SELECT`, а также научиться использовать сортировку и шаблоны поиска.

## Среда выполнения

В работе используется:

- **СУБД:** Microsoft SQL Server 2019 Developer
- **Среда запуска:** Docker Desktop
- **Клиент:** Visual Studio Code
- **Расширение:** SQL Server (mssql)
- **Учебная база данных:** AdventureWorksLT2019
- **ОС:** macOS, Apple Silicon
